# 简易项目门户设计

## 目标

把面向工程师的入口收敛为 GitLab 与铁炉堡两个清晰区域，让没有 Git 基础的用户先选项目，再选上传或下载，最后进入已有的分步流程。

## 页面结构

- 左侧仅保留“项目”“历史记录”，底部保留“设置”。
- 项目首页顶部显示 GitLab 和铁炉堡两个页签。
- GitLab 页签显示项目概况。项目条目本身不显示操作按钮，点击整个条目进入项目操作页。
- 项目操作页只提供“上传这台电脑的修改”和“下载服务器的新内容”两个选择，并可返回项目列表。
- 铁炉堡页签独立显示登录说明和官方页面入口，不复用 GitLab Token、SSH 或权限状态。
- 账户页使用统一的卡片、编号、状态和按钮样式；长教程仅通过问号展开，手动 SSH 设置归入“专业显示”。

## 权限边界

- GitLab 操作继续使用桌面端安全保存的 Token 和电脑身份钥匙。
- 铁炉堡由其官方 SSO 页面管理登录、权限、项目和下载。
- 软件不提取、保存或复用铁炉堡 Cookie，不调用未获授权的私有接口。

## 验证

- 项目条目无内部操作按钮，点击后才能选择上传或下载。
- 两个页签的选中状态和内容明确。
- 原有上传、下载、MR、历史及账户测试保持通过。
- 公开构建继续通过敏感信息审计。
